One in-depth presentation this month by Jeremy Olliver:

**Automate your deployments with Chef**

We all know that the best form of documentation is the executable kind, you follow this already with your tests, now do the same with your server configuration. This month Jeremy takes a look at Chef - a popular open source server configuration management tool written in ruby - an overview of how it works, how to write your own cookbooks and recipes, with a focus on how to deploy a ruby web framework using it.
