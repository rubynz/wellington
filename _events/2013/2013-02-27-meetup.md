Presentation:

This is what we actually had scheduled for the last meeting last year, except it ended up conflicting with other stuff like the Hobbit release, so we're doing it this month instead.
Andy Newport from Powershop is talking about the development of Nitra, a multiprocess distributed RSpec and Cucumber runner. It arose out of a need to be able to throw commodity hardware at their test suite to alleviate the horrible execution time that they're now stuck with for various rather boring reasons.
