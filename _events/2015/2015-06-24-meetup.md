Nick Malcolm will be talking about Two Factor Authentication, and how to add it to your rails app using Authy.

Josh Brodie is going to be talking about reflected file download, a fairly recently identified attack class which causes victims to download attacker-defined files, believing they come from a trusted site. It's especially common in JSON APIs.

Andrew Kampjes is giving a TL;DR overview of the common security issues in Rails projects and how to avoid them.

Doors open at 5:30pm with talks starting around 6pm.
