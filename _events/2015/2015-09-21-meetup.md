This month we're doing a "show and tell" event again. We have not organised a single presenter, but instead it'll be an open mic night where anyone can get up and show off what they've been doing. This could simply be about a small script, a new gem, a kick-ass feature, a side project, help with a problem, or something else.

Been to one of the "This is what I've been doing" night time presentations at NZ Railscamp? This is basically that. If nobody has anything to show Matt has volunteered to do an metaphorical dance highlighting has learning from tracking down memory leaks.

So please bring your laptops (we cater for all projector connections) and your code. There is no minimum time required for showing something, it could simply be a static screen with some code that takes a minute to explain. I'll apply a max of ~10 minutes though so as to give everyone an opportunity to talk.
